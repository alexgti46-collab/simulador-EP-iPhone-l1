SIMULADOR DE ESCORIA – VERSIÓN WEB INSTALABLE (PWA)

Este paquete permite publicar la interfaz v2.3 como aplicación web instalable en iPhone y Android. No es un APK ni un archivo IPA.

PUBLICACIÓN NECESARIA
1. Sube TODO el contenido de esta carpeta a un repositorio de GitHub (por ejemplo, una carpeta raíz de un repositorio nuevo).
2. En GitHub abre Settings > Pages.
3. En Build and deployment selecciona Deploy from a branch.
4. Selecciona la rama main y la carpeta /(root), y guarda.
5. Espera a que GitHub Pages publique el sitio y abre la URL HTTPS que te entrega.

INSTALAR EN IPHONE
1. Abre la URL publicada en Safari (no dentro de WhatsApp).
2. Toca Compartir.
3. Selecciona Añadir a pantalla de inicio.
4. Confirma Añadir.

INSTALAR EN ANDROID
Abre la misma URL en Chrome y usa el menú > Instalar aplicación o Añadir a pantalla de inicio.

DATOS E HISTORIAL
El historial se guarda localmente en el navegador/dispositivo. No se sincroniza automáticamente entre iPhone y Android. Exporta el CSV desde la aplicación para conservar una copia. Tras la primera carga, el service worker permite abrir la interfaz sin conexión; la primera visita sí requiere internet.

NOTA
La PWA mantiene los cálculos y la interfaz incluidos en el index.html de la versión 2.3. Debe validarse en Safari y contrastarse con Excel antes de usar resultados para decisiones operativas.
